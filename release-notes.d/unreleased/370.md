Fix the `prometheus-budget` gate on a stock llm-d install: its primary source queried `inference_extension_flow_control_queue_size`, which only exists when EPP runs the flow control plugin, so the gate silently served its fallback budget. A source based on `inference_pool_per_pod_queue_size` (part of EPP's base metric set) is now tried between the flow control and vLLM sources. The resolved PromQL for each cascade tier is logged at startup, and the new `llm_d_async_async_gate_metric_source_available` gauge distinguishes a fallback budget from a real reading of the same value.
