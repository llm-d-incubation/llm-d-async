New optional OpenAI API compatible frontend (`frontend/` module, chart flag
`frontend.enabled`) serving three modes against existing async queues: enqueue
(202 plus fetch by id), wait (held connection), and direct (labeled proxy to
the inference gateway). Queue configs gain `result_ttl_seconds`, deadline
aborted sends now classify as `DEADLINE_EXCEEDED`, and the tier-priority merge
policy gains `lane_objectives` for per-lane objective stamping.
